Before you ask

How is it fast?

The apps split each file into parts and fetch 8 at once, the way a download manager does, and fetch the small fragments of streamed videos 4 at a time. Files come in 10 MB ranges, which avoids the slowdown some sites put on one long connection. The apps download straight from the site to your device, so the speed is your line and the site's. On this page, files of 8 to 80 MB are fetched as 4 slices at once in Chrome or Edge on a PC. If a site does not allow that, it falls back to one stream.

Can I share a link to EqDownload from my iPhone?

Yes, with a Shortcut that you make once. Open the Shortcuts app and tap +. Tap the name at the top and choose Details, then turn on Show in Share Sheet and set it to accept URLs and Text. Add the action Text and type https://eqdownload.vercel.app/?url=, then tap after it and insert the variable Shortcut Input. Add the action Open URLs and give it that text. Name the shortcut EqDownload. Now in Safari, YouTube, TikTok or any app, tap Share, then EqDownload. The page opens with the link already checked. The same limits as the page apply: sites that block this server still need the Windows or Android app.

How do I save a video on my iPhone?

Paste the link above and press Find. Tap a quality. Safari opens or downloads the file. Use the Share button, then Save to Files or Save Video. If the page says the site is blocked, send this page to a PC or an Android phone and use the app there.

Why is there no iPhone app?

iOS does not let an app run yt-dlp the way Windows and Android do, and building and signing an iPhone app needs Apple’s paid developer account. None is planned. This page covers the sites a browser can reach.

Which sites work in the browser?

Sites that serve a plain video or audio file, such as the Internet Archive, and TikTok. TikTok videos save without the TikTok logo; some TikTok links are refused for the server’s address, and the apps then work better. YouTube blocks the server this page runs on with a bot check. Vimeo and Reddit want a login. Dailymotion and SoundCloud stream in pieces that need ffmpeg to join. The apps run on your own connection with ffmpeg and handle all of those.

Why the warnings, and is the file genuine?

Windows shows an unknown-publisher warning because the exe is not code-signed: choose More info, then Run anyway. To check a file, compare its SHA-256 with these values from the release.

What does it send about me?

The apps send nothing to anyone but the site you pasted and, on a button press, GitHub. This page is different: the link you paste goes to this page’s server, which asks the site for the file list. The function stores nothing, but Vercel, the host, keeps ordinary request logs that include the link. For sites whose file links need cookies, such as TikTok, the video file also passes through that server on its way to you, because TikTok’s file links only work with cookies a browser cannot send. Thumbnails load from the video site straight to your device. There are no ads, accounts or analytics.

Is the Android app tested?

It builds, is signed, and passes its unit tests. It has not been run on a phone yet. Treat it as untested until you try it, and report what breaks on the GitHub page.
